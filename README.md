**Emberpass Airlift** — an original 3D flight game that plays offline in a desktop browser from static files. You are the bush pilot of Emberpass Valley at dusk: three sorties (a ring run down the valley, a supply drop on Ember Camp, and a slalom in the pass wind), a real lift-and-stall flight model with fuel and damage, chase and cockpit views with a lit instrument panel, and landings scored on touchdown zone, sink rate and centreline. The 3D world is rendered by a small software renderer written for this game — no engine, no libraries, no network — and every sound is synthesised with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Enter. Fly with the arrow keys or WASD (or hold the mouse and steer), Shift/Ctrl for throttle, Space to brake, F to release the crate, C to swap chase and cockpit views, P to pause. Node 22.18 or later; nothing to install.
